# Neon Ledger

An original cyberpunk shopkeeper sim for iPhone, built as an offline web app (PWA).

**Play:** https://bongbingbing.github.io/Is-Stolen/ → open in Safari → Share → **Add to Home Screen**.

- Design: [docs/DESIGN.md](docs/DESIGN.md)
- Architecture & contracts: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Team process: [docs/TEAM.md](docs/TEAM.md)

Local dev: `./tools/serve` then open http://localhost:8765/ · Tests: `./tools/test`
(Requires the Python venv: `python3 -m venv .venv && .venv/bin/pip install playwright pytest && .venv/bin/python -m playwright install chromium`.)
